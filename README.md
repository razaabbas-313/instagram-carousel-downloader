# 📸 InstaSlide — Instagram Carousel to PDF Converter

A lightweight, open-source web application built with Streamlit and Python that converts multi-image Instagram carousels into high-resolution, neatly structured PDF documents.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/)
[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## ✨ Features

- **Direct Link Extraction:** Paste any public Instagram carousel (`/p/`, `/reel/`, or `/tv/`) URL.
- **Multiple Page Layouts:**
  - **Original Dimensions:** Keeps native photo aspect ratios and resolutions.
  - **A4 Portrait:** Centers slides on standardized A4 pages (ideal for study notes and cheat sheets).
  - **A4 Landscape:** Formats landscape-oriented carousel slides cleanly.
- **Visual Slide Preview:** View all carousel slides in a clean thumbnail grid before downloading.
- **No Login Required:** Works with all publicly accessible posts without storing or requiring your Instagram credentials.
- **In-Memory Processing:** Images are converted on the fly without cluttering disk space.
